# Tools

Free tools for building with Claude. Each one is used for real before it is handed over, and each folder's README says what it does, how to install it and how it has done so far.

| Tool | What it does |
|---|---|
| [Heard](heard/) | Claude says back what you asked for before it starts, and a Sharpen button turns a rough draft into a clear prompt. |
| [Slingshot](slingshot/) | Before a big job starts, Claude shows you the most ambitious version worth doing (a higher goal, the made-up limits gone, a field from far outside the task) as a short plan, and you choose. |

New tools go out first in my weekly email, Value Prompt, the short version of what's new in AI and healthcare. [Get it here](https://valueprompt.pages.dev/?utm_source=github&utm_medium=tool&utm_campaign=nico-tools).
